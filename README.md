# 🤖 جارویس — دستیار صوتی فارسی

یه دستیار هوشمند شبیه جارویسِ مرد آهنی که روی گوشی اندرویدت اجرا میشه.

بگید **«جارویس»** و جواب میده: **«بله، چه کاری باید انجام بدم؟»** 🎙️

## ✨ قابلیت‌ها

| قابلیت | مثال دستور صوتی |
|---|---|
| ⏰ هشدار (زمان مطلق) | «یه هشدار برای ساعت ۲ بعد از ظهر تنظیم کن» |
| ⏰ هشدار (زمان نسبی) | «۲۰ دقیقه دیگه هشدار بذار» یا «نیم ساعت دیگه بیدارم کن» |
| 📞 تماس | «با علی تماس بگیر» یا «با ۰۹۱۲۱۲۳۴۵۶۷ تماس بگیر» |
| 💰 قیمت ارز دیجیتال | «قیمت بیت کوین» / «قیمت اتریوم چنده» |
| 🔥 اخبار ارز دیجیتال | «اخبار ارز دیجیتال رو بده» |
| 📖 جستجو و خواندن | «درباره هوش مصنوعی بگو» یا «لندن چیه» (از ویکی‌پدیا فارسی) |
| 🔍 باز کردن گوگل | «سرچ کن نرخ ارز» یا «... رو توی گوگل باز کن» |
| 🧮 ماشین حساب | «۳ به علاوه ۵ چنده» / «۱۲ ضربدر ۴ چنده» |
| 🗓️ ساعت و تاریخ شمسی | «ساعت چنده» / «امروز چندمه» |
| 🧠 هوش مصنوعی عمومی | هر سوالی داری (نیازمند فعال‌سازی در تنظیمات) |

زمان‌ها رو هم می‌فهمه: «ساعت دو بعد از ظهر»، «۸ و نیم صبح»، «۹ شب» و اعداد فارسی و حرفی.

## 📱 نصب روی گوشی

میکروفن و نصب PWA فقط روی آدرس **https** کار می‌کنن، پس برنامه باید روی یه آدرس اینترنتی باشه. ساده‌ترین روش رایگان: **GitHub Pages**

### مرحله ۱: آپلود فایل‌ها

1. توی [github.com](https://github.com) ثبت‌نام/ورود کن (رایگانه)
2. دکمه **New repository** رو بزن؛ اسم دلخواه بذار (مثلا `jarvis`)، روی **Public** بذار و **Create**
3. توی صفحه مخزن، روی **uploading an existing file** کلیک کن
4. **هر ۴ فایل و پوشه** پروژه رو بکش و رها کن:
   - `index.html`
   - `app.js`
   - `manifest.json`
   - `sw.js`
   - پوشه `icons/` (هر دو عکس)
5. روی **Commit changes** بزن

### مرحله ۲: فعال‌سازی GitHub Pages

1. توی مخزن، برو **Settings ← Pages**
2. قسمت **Source** گزینه **Deploy from a branch** رو انتخاب کن
3. برنچ `main` و پوشه `/ (root)` رو انتخاب کن و **Save** بزن
4. چند دقیقه صبر کن؛ آدرس سایتت این میشه:
   `https://نام-کاربری.github.io/jarvis/`

### مرحله ۳: نصب روی گوشی

1. با **کروم اندروید** اون آدرس رو باز کن
2. اولین بار اجازه **میکروفن** رو بده
3. از منوی سه‌نقطه کروم، **Add to Home screen / افزودن به صفحه اصلی** رو بزن
4. از این به بعد جارویس مثل یه اپ معمولی از صفحه اصلی گوشیت باز میشه 🎉

> روش‌های دیگه هاست رایگان: Vercel ،Netlify ،Cloudflare Pages — هر کدوم که راحت‌تری. فقط پوشه `jarvis` رو آپلود کن.

## 🎙️ نحوه استفاده

- **دکمه گرد وسط صفحه**: لمس کن، دستورت رو بگو (میکروفن فقط وقتی دکمه رو زنی فعال میشه — باتری رو نمی‌سوزونه)
- **حالت گوش دادن**: کلید کنار صفحه رو روشن کن؛ جارویس مدام گوش میده و هر وقت فقط بگی «جارویس» جواب میده. (مصرف باتری بیشتری داره)
- **تایپ کردن**: اگه صدات دردسر داشت، دستورت رو توی کادر پایین صفحه بنویس — همه قابلیت‌ها با متن هم کار می‌کنن

### مخاطبین برای تماس

دکمه **👤** → اسم و شماره هرکی رو که زیاد باهاش تلفنی حرف می‌زنی رو ذخیره کن. بعد کافیه بگی «با اسمش تماس بگیر».
(تماس صفحه تماس گوشی رو با شماره آماده باز می‌کنه؛ خودِ تماس با یه لمس تأیید انجام میشه — محدودیت امنیتی مرورگرهاست.)

### فعال‌سازی هوش مصنوعی (اختیاری)

دکمه **⚙️** → کلید «هوش مصنوعی» رو روشن کن و اطلاعات یه سرویس سازگار با OpenAI وارد کن:

- **آدرس API**: مثلا `https://openrouter.ai/api/v1` (پیشنهادی، چون مستقیماً از مرورگر پشتیبانی می‌کنه) یا `https://api.openai.com/v1`
- **کلید API**: از حساب کاربری سرویس بگیر
- **مدل**: مثلا `gpt-4o-mini` یا هر مدل دیگه‌ای که سرویس‌ت داره

بعد از این، جارویس به **هر سوالی** جواب صوتی میده. کلید فقط توی حافظه محلی گوشی خودت ذخیره میشه و فقط به همون سرویس فرستاده میشه.

## ⚠️ نکات مهم

- **هشدارها**: تا وقتی جارویس باز باشه (حتی در پس‌زمینه) کار می‌کنن — با نوتیفیکیشن، صدا و ویبره. اگه گوشی یا مرورگر کامل بسته باشن، هشدار از دست میره. برای هشدارهای حیاتی از ساعت خود گوشی استفاده کن. (محدودیت ذاتی وب‌اپ‌ها؛ فقط اپ‌های نصبی اندروید به هشدار واقعی همیشه‌کار دسترسی دارن)
- **تشخیص گفتار**: برای شنیدن صدات اینترنت لازمه (موتور گوگل روی دستگاه پردازش نمیشه). فارسی رو خیلی خوب می‌فهمه ولی مثل هر تشخیص گفتاری، گاهی ممکنه کلمه‌ای رو اشتباه بفهمه.
- **صدا**: برای جواب دادن صوتی، صدای فارسی روی گوشی باید نصب باشه (روی بیشتر گوشی‌های اندرویدی هست). اگه صدای فارسی نبود، جواب‌ها فقط نوشته میشن. می‌تونی از تنظیمات صدای موردعلاقه رو انتخاب کنی.
- اعداد و زمان فارسی (چهارشنبه، ۱۴:۳۰، ۲۰ آبان) کاملاً پشتیبانی میشن.

## 🛠️ فایل‌های پروژه

| فایل | توضیح |
|---|---|
| `index.html` | ظاهر برنامه (فارسی، راست‌به‌چپ، تم نئون آبی) |
| `app.js` | مغز جارویس: تشخیص گفتار، پارس دستورها، تماس، هشدار، APIها |
| `sw.js` | سرویس‌ورکر: کارکرد آفلاین ظاهر برنامه + نوتیفیکیشن هشدارها |
| `manifest.json` | مشخصات PWA برای نصب روی صفحه اصلی گوشی |
| `icons/` | آیکون‌ها |
| `make_icons.py` | اسکریپت ساخت مجدد آیکون‌ها (اختیاری) |
| `docs/screenshot.jpeg` | اسکرین‌شات برنامه |

## 🔧 توسعه بیشتر

- اگه فایل‌ها رو تغییر دادی، توی `sw.js` مقدار `jarvis-v1` رو به `jarvis-v2` تغییر بده تا همه گوشی‌ها نسخه جدید رو ببینن.
- لیست ارزهای دیجیتال رو می‌تونی توی `app.js` توی آرایه `COINS` کم و زیاد کنی.
- دستورهای جدید هم تابع‌های `route*` توی `app.js` هستن.
