هوش مصنوعی (پاسخ به هر سوالی)

اگه کلید API یه سرویس سازگار با OpenAI داری، واردش کن تا جارویس به هر سوالی جواب بده. پیشنهاد ما OpenRouter است که از فراخوانی مستقیم مرورگر پشتیبانی می‌کنه (در OpenRouter آدرس API میشه https://openrouter.ai/api/v1). بدون کلید هم جستجوی ویکی‌پدیا و بقیه قابلیت‌ها کار می‌کنن. کلید فقط روی گوشی خودت ذخیره میشه.
